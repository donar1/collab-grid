# docs/

项目文档目录，存放架构设计、版本说明等技术文档。

## 文件清单

| 文件 | 作用 |
|------|------|
| `ARCHITECTURE_LAYERS.md` | 三层架构设计文档：第一层操作界面/通用表格能力、第二层核心业务（产品/客户/订单/账单/库存）、第三层数据大屏与财务核算 |
| `V0.3_RELEASE_NOTES.md` | V0.3 版本说明：路由拆分、P0 安全修复、模块化改造记录 |
| `V0.3.1_PERMISSION_MATRIX.md` | V0.3.1 权限矩阵与内外库分离说明 |
| `COLLABGRID_PROJECT_GUIDE.md` | 项目总览文档：概述、架构、API、编程思路、扩展指南（原 README.md） |

## 文档规范

- 新增架构决策记录（ADR）放入此目录
- API 文档、部署文档、角色权限矩阵等后续补充也放入此目录
- 命名规则见项目根目录 `NAMING_CONVENTIONS.md`
