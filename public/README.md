# public/

前端静态资源目录，由 Express 静态文件中间件托管。

## 文件说明

| 文件 | 作用 |
|------|------|
| `index.html` | SPA 入口页面，加载所有 CSS 和 JS |
| `app.js` | 主应用逻辑：认证、空间管理、表格渲染、Dashboard、作业中心、诊断中心、模板初始化入口 |
| `styles.css` | 全局样式：表格视图、表单、Dashboard 大屏、作业配置面板 |

## 子目录

### `modules/`
从 `app.js` 抽离的独立功能模块：

| 文件 | 作用 |
|------|------|
| `clipboard.js` | 剪贴板操作：复制/粘贴单元格、跨表格粘贴 |
| `keyboard.js` | 键盘快捷键：方向键导航、Tab 切换、Delete 清空、Ctrl+Z 撤销 |
| `fields.js` | 字段渲染器：根据字段类型（文本/数字/选择/日期/关联/公式等）生成对应的编辑控件 |
| `links.js` | 关联字段交互：关联选择弹窗、关联记录搜索、多选管理 |

### `assets/`
静态资源文件（图片等）。
