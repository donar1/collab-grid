# routes/core/

第二层：核心业务路由。按五个业务对象（产品、客户、订单、账单、库存）组织，每个文件负责对应业务模板的初始化和专属 API。

## 文件说明

| 文件 | 负责的业务对象 | 包含的模板/API |
|------|---------------|----------------|
| `customers.js` | 客户 | 资源档案中心、员工档案中心、业务锁定区、状态变更日志 |
| `products.js` | 产品 | 产品名称数据源区、产品信息区 |
| `orders.js` | 订单 | 订单管理区、批量订单导入（`/api/bases/:baseId/bulk/orders`） |
| `inventory.js` | 库存 | 库存商品区、出入库操作区、库存流水区 |
| `bills.js` | 账单 | 财务结算对象区、应收/应付结算明细区、收付款流水区、红冲/退款/撤单处理区、账单明细生成（`/api/bases/:baseId/finance/generate-details`） |

## 业务对象关系

```
客户（资源档案）──锁定关系──→ 产品
        │                        │
        └──付款方/收款方──→ 订单 ──→ 库存（出入库）
                              │
                              └──→ 账单（应收/应付明细）
```

## 依赖

- 由 `server.js` 通过 `coreRouteContext` 注入共享依赖
- 引用 `layers/businessRelations.js` 的业务对象定义
